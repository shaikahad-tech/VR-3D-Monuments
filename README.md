

## 🏛️ Overview

This project creates an immersive VR museum experience where visitors can explore photogrammetry-captured historical monuments across 4 themed exhibition rooms connected by a central corridor.

### Museum Layout
```
                    ┌──────────────┐
                    │   Room 1:    │
                    │ Iraq Section │
                    │(Nahum Shrine)│
                    └──────┬───────┘
                           │
    ┌─────────────┐  ┌─────┴─────┐  ┌──────────────┐
    │   Room 4:   │──│ CORRIDOR  │──│   Room 3:    │
    │   Aerial    │  │  (Hub)    │  │ Archaeolog.  │
    │Photogramm.  │  └─────┬─────┘  │   Shards     │
    └─────────────┘        │        └──────────────┘
                    ┌──────┴───────┐
                    │   Room 2:    │
                    │   Prague     │
                    │  Monuments   │
                    └──────────────┘
```

### Key Features
- **Grab & Rotate** — Pick up monuments and rotate them for detailed inspection
- **Teleportation** — Comfort-focused locomotion with waypoint anchors
- **Guided Tour** — Auto-navigated tour through all exhibits with narration
- **World-Space UI** — Info panels, wrist HUD, waypoint indicators
- **Performance Optimized** — LOD, occlusion culling, texture streaming for Quest

## 🚀 Quick Start

1. **Create Unity Project** — Unity 2022.3 LTS, URP template
2. **Copy Files** — Copy `Assets/` and `Packages/manifest.json` into your project
3. **Install Packages** — Unity will auto-resolve from manifest
4. **Run Setup Wizard** — `Tools > Virtual Museum > Setup Wizard`
5. **Import Models** — Add your `.FBX`/`.OBJ` photogrammetry models
6. **Create Exhibits** — `Assets > Create > Virtual Museum > Exhibit Data`
7. **Bake Lighting** — `Window > Rendering > Lighting > Generate Lighting`
8. **Build** — `File > Build Settings > Android > Build`

## 📁 Project Structure

```
Assets/_Project/
├── Scripts/
│   ├── Core/           — VirtualMuseumManager, RoomManager, ExhibitData, GameEvents
│   ├── Interaction/    — MonumentGrabInteractable, Inspector, TriggerZone, Portal
│   ├── Locomotion/     — Teleport, ComfortSettings, GuidedTour
│   ├── UI/             — InfoPanel, HUD, WaypointIndicator, MainMenu
│   ├── Environment/    — ArchitectureBuilder, Lighting, Pedestals, Particles
│   ├── Optimization/   — LOD, TextureQuality, Occlusion, PerformanceMonitor
│   ├── Audio/          — AmbientAudio, SpatialAudioTrigger
│   └── Data/           — ExhibitDatabase
├── Editor/             — SetupWizard, ModelImportProcessor, ExhibitDataEditor
├── Shaders/            — PhotogrammetryLit.shader
├── ScriptableObjects/  — ExhibitData SOs, RoomConfig SOs
├── Prefabs/            — Generated by setup wizard
└── Scenes/             — Museum scenes
```
